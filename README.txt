SHANESH'S FIRST BIRTHDAY INVITATION
===================================

Included:
- index.html: invitation page
- style.css: colours, layout and responsive design
- script.js: guest personalisation, countdown and RSVP link
- birthday-music.mp3: add your chosen licensed/royalty-free music file here

IMPORTANT CUSTOMISATION
1. Open script.js.
2. Replace YOUR_WHATSAPP_NUMBER with the family's WhatsApp number in international format, digits only.
   Example format for Sri Lanka: 94771234567 (example only).
3. Add an audio file named birthday-music.mp3 in this same folder.
   Use a track you have permission to use. Music starts only after the visitor taps Play music.
4. To change the invitation greeting for a guest, add ?name=GuestName to the URL.
   Example: https://your-site.vercel.app/?name=Mrs.Sumeiya
   Spaces can be written as %20 or +.

PREVIEW LOCALLY
- Open index.html in a browser.
- For best results, use VS Code with the Live Server extension.

PUBLISH ON VERCEL
1. Create a free account at https://vercel.com/
2. Create a GitHub repository and upload the three website files (plus your music file).
3. In Vercel, choose Add New -> Project and import that repository.
4. Keep the default settings and click Deploy.
5. Your site will receive a public URL.
6. Share personalised links by adding ?name=GuestName to the end of the URL.
